## A：四轮下探后的结构反转

1. 先选定同一级别整段下跌的起始峰和计数范围。内部反弹不能清零计数，也不能用浅回踩替换较大波段的D。
2. 至少出现4个依次更低的独立波段低点：LL1、LL2、LL3、LL4。两个低点之间必须有经已完成K线确认的独立反弹，不能把连续下跌的4根K线算成4个低点。
3. 这些低点之间的反弹峰依次降低：LH1、LH2、LH3。若已超过前一个反弹峰，应标HH／结构转强，不能继续硬标LH。四低点完成之前已经转强的情形不强塞进本路线，另作结构审查。
4. 第四低点之后反弹超过此前最近的同级反弹峰，形成HH。这里不用突破整段下降起点的最高价。
5. 随后回踩形成HL，明显高于最后一个较大D，且触发前未被破坏。
6. 当前15分钟K线盘中突破**前一根完整15分钟K线的最高价，含上影线**，触发局部入场参考；不等当前K线收盘。

结构顺序：`LL1 → LH1 → LL2 → LH2 → LL3 → LH3 → LL4 → HH → HL → 盘中突破`。

“独立／同级”目前使用逐根审查后的波段标注及其可知时间，不以任意一根小反弹自动确认父级波段。验证器检查这些事实的顺序、价格关系与可知时间；**尚不是已经验证的通用自动波段分级算法**。

## B：连续急跌的两个分支（单例预览）

**共同起点：** 完整15分钟阴线创setup新低，`max(开盘, 前收盘)−最低 ≥ 2 × 急跌开始前ATR14`。
首轮完整阳线反弹（且其低点守住D）出现前，允许后续完整15分钟K线继续延伸D，不强求每根≥2ATR或收阴。
未完成K线创新低时，先停止触发准备，等该根结束才可更新D；不能提前引用其最终低点。
完整反弹形成后再破D，原准备失效，须等待新急跌锚点。缺失／不完整结构数据清理准备状态，不补K线。

### B1：连续急跌后的首次止跌突破

#### 历史B1：原保存结果的定义

此前机械实现允许同一根完整15分钟K线自身创新低后拉回，同时提供D和突破参考；不要求随后已有独立15分钟守D。2026年10月15日#5按该旧定义B1通过但B2不通过。入场前1分钟微型HL不能替代新定义的15分钟确认。见[原始逐根审查](investigations/2026-11-08_BTC_TRADE5_B1_BAR_AUDIT.md)。

- 前一根完整K线收盘离开其最低价，可以仍是阴线，不预设下影必须超过50%。
- 当前盘中守住当时已完成D，并突破前根完整最高价＋$0.01；这是首次止跌确认，单有下影不买。
- 不要求先有完整阳线反弹及独立HL。HL明确留空，不能把当前反弹伪装成已经完成回踩；B2的HL容差不适用于不存在的HL。
- 每个已完成D只保留第一次B1触发，延伸出更低且已完成的新D后才可重新准备。

### B2：反弹回踩HL后的突破

- 先有完整阳线反弹，低点高于继承后的较大D；之后回踩形成已完成HL。
- HL高于D至少0.10倍入场前ATR，触发前仍守住，然后盘中突破前根完整最高价。
- 不要求4个LL，也不要求先突破第一轮反弹峰。首轮反弹峰仍要作为近处阻力记录。

两支都沿用D−0.25倍入场前ATR初始保护、0.10 ATR追价上限、每边2bps成本、净目标空间为正及既有退出。
**候选D向下延伸绝不使已持仓止损下移。** 持有B1时遇到B2，只登记信号，不自动加仓。

## 两路共同的入场与保护

| 项目 | 现有研究要求 |
| --- | --- |
| 数据 | 同一来源的真实分钟记录；参考15分钟K线需有15根真实分钟，不补价、不插值；缺失则显式报告 |
| HL容差 | A／B2的HL高于较大D至少0.10倍入场前ATR且触发前未破；B1不虚构HL |
| 突破线 | 前一根完整15分钟最高价＋$0.01研究增量；分钟最高价需超过这条线 |
| 入场参考 | 触发线与触发分钟开盘价取较高者；仅是模型参考，不是已验证成交价 |
| 追价上限 | 不超过突破线＋0.10倍入场前ATR；超出则放弃该参考入场 |
| 初始止损 | 较大D−0.25倍入场前ATR；不临时改用较浅HL以凑风险收益比 |
| 目标 | 信号前已知的重要波段阻力，保留原目标算法与缓冲；记录近处反弹阻力，不用后来的上涨倒选目标 |
| 成本 | BTC产生信号；ETF零佣金假设，仍按每边2bps价差／滑点研究模型，不能当成ETF实际收益 |
| 风险门槛 | 用户最新标准：目标扣成本后有严格为正的预期利润空间；2R降为提示；目标缺失仍不合格；不足2R只作提示，不因这一项阻止候选 |
| 止损生效 | 假设模型入场后立即保护；后续只有新高及已确认同级波段低点才可上移，不被内部小回踩替换 |
| 退出 | 普通目标保留25%／75%；保护止损、既定末分钟长上影、创新高后下一根跌破全振幅中点，退出全部剩余仓位；最早事件优先 |

ATR_before_impulse与ATR_before_entry是两个不同时间点的量。急跌分类用急跌前ATR；入场的缓冲及追价限制用入场前ATR，不能混用以改善结果。

## 失效、重建与重复信号

- 触发前HL被破坏：当前局部触发准备失效。若较大D仍有效，必须等待新的完整反弹／回踩结构重新审查，不能沿用已经失效的HL。
- 较大D被跌破：A或反弹完成后的B准备失效。B在首轮完整反弹前可在新低K线结束后延伸同段D；不能提前使用未知低点，不能改变已经开仓的保护。
- A与B同一时刻都符合：保留双路线标签，但同一D／HL／触发／保护与目标的信号只统计一次；已有持仓时不因此重复加仓。
- 信号之后跌回触发线下，不撤销已经出现的盘中触发，也不能将它改写成“收盘确认”。按既定保护和退出记录后续结果。
- 未定义任意“几根K线过期”或新的止损宽度；此处没有额外添加参数。

## 实现边界与验收

`trading_desk/btc_entry_rules.py`提供A、B及共同风险筛选的独立研究验证器，无网络或券商调用。输入为真实行情与事先审查的结构事实／known-at时间；输出分开记录setup、price signal、risk及qualified candidate。

本次验收：两例均能识别各自结构及实际分钟突破；3个低点不能伪装成4个；普通阴线不能伪装成急跌；未完成反弹、未来ATR／波段确认、触发前HL失效均拒绝；低于2R仍显示提示，净目标空间不为正或目标缺失仍拒绝。North Star是可追溯的当时证据、零虚构行情、零订单提交，而非为提高胜率改标签。

**A/B已接入网页回测按钮、自动结构草案、去重及全部信号审查。** 15分钟转折用左右各一根完整K线确认；保留嵌套下降范围，选结构合格且起点较早的范围，不按利润挑选。11/7程序标5段而人工标4个较大波段，分级等价性仍需审查。
