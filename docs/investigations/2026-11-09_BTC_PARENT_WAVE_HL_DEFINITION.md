# 同一级别父波段 HL：三例入场时点定义复核

区分父底归属、当前反弹链和早期 HL 候选，避免用后续盈亏倒选定义。

Last Updated: 2026-11-09
Status: Definition proposal and read-only evidence; no rule promotion
Audience: 交易桌使用者和研究维护者

## Overview

三例在原入场时已经存在可知差别：#13 的当前父级反弹结构早已失败，
后来仍借用完整的祖先 D；近端反弹也已经形成确认高点，原触发线未被突破，
随后参考线下移才入场。11/09 03:17 与 #90 都在近端低点刚确认后的第一根
触发，不存在同样的已确认小时底失效链。但 **03:17 当时只能标为父底回测中的
HL 候选，不能称为已经确认的父级上涨延续**。

本次定义是结构标签与研究建议，不是已批准入场过滤器。没有计算新收益，
没有改 P1、C、0.2、止损、退出或 Live Paper，也没有运行整月策略。

## 拟议定义：同级别是归属关系，不是价格高于任意旧低点

### 1. 先固定正在研究的父段 D → H

父 D、其后的推动峰 H、各自出现和确认时间，必须在观察新回踩 L 之前或
当时确定。不能看到 L 太低，就临时跳到更早、更低的 D 来让它成为 HL。
本次保留现有 C 的小时父 D 与十五分钟确认/触发资料，不添加振幅或根数阈值。

### 2. 区分祖先支撑与当前有效的反弹结构

D 价格仍未跌破，只说明祖先支撑完整。如果 D → H 之后，已经形成较近的
同尺度回踩低点 L、较低反弹峰 LH，再跌破 L，则这一次延续尝试已失败。
旧 D 可以继续是更大级别的支撑，但不能自动继续为原来那一轮延续提供资格。
之后重新建底，应标出新父段及其确认依据；若是在旧 D 附近做反转试探，应
标成祖先支撑重测，不能不加区分地称为原父级上涨延续。

本次用相同的完整小时转折作为三例的历史结构核对尺。它们是已有的价格证据，
不等同于已验证所有小时转折都属于独立大波段，更不能把转折数量当作 P1 计数。

### 3. 父级回撤允许内部多个十五分钟 LL/LH

大波段回撤内可以有多轮局部降高降低。L 低于上一局部十五分钟低点，
不自动否定其相对父 D 的 HL 候选身份。因此不要求它高于所有内部小低点。
同样，某个十五分钟小反抽成为 HH，也不自动修复已破坏的小时父级结构。

### 4. 近端买入要说明属于哪一轮反弹

HL 刚确认后的第一次突破，与 HL 后已经反弹、形成确认峰、再回踩后买入，
是两种不同的局部状态。后者不能悄悄沿用第一次机会的身份，只因为下一根
最高价降低，就声称原反弹已经突破。应分别记录当前峰、新回踩是否确认、
旧突破参考线是否真正收复。

“冻结首次触发线”或“允许新回踩后重建触发线”是后续待研究的执行政策；
本次只标清事实，不选取、不接入其中任一政策。

### 5. 分开“确认低点形状”和“确认上涨延续”

完整邻居 K 线或 P1 只能确认低点/反弹有一定形状、持续时间和幅度。
回踩 L 高于当前父 D，且父级归属尚有效时，可标为**同级 HL 候选**。
之后突破对应父峰 H 才能进一步验证延续成功；这项后来的验证不能倒用于
筛选原入场，也不意味着必须等到突破大峰才能进行早期试探。

## 三例结论与当时证据

均为纽约时间；#13 为 C 比较基准序列 10/14 21:32，#90 为 10/28 17:16。
11/09 为 EST，其余为 EDT。结构只使用原入场之前已观察的分钟及已完成 K 线。
原触发价格只是历史分钟参考，不是精确秒级或额外成交。

| 入场时事实 | #13 | 11/09 03:17 | #90 |
|---|---|---|---|
| 原父 D | 10/12 20:52，80,942.81 | 11/08 16:55，73,530.09 | 10/28 12:46，80,283.50 |
| 选用反弹峰 H | 10/13 04:15，84,073.29 | 11/08 18:16，75,615.44 | 10/28 16:02，81,720.51 |
| 近端 L | 10/14 20:52，81,301.36 | 11/09 02:58，73,629.55 | 10/28 16:46，80,909.68 |
| L 确认时间 | 21:15 | 03:15 | 17:15 |
| H 后是否已有确认小时底、随后失败 | 有，多次可见 | 没有找到同类已确认链 | 没有找到同类已确认链 |
| L 后、入场前是否已有确认十五分钟反弹峰 | 有，21:09 的 81,820.85，21:30 确认 | 无 | 无 |
| 是否在 L 确认后的第一根触发 | 否，第二根，且参考价已降低 | 是，03:15–03:30 内 | 是，17:15–17:30 内 |
| 研究标签 | 原父级延续已失败后的祖先支撑反抽；触发又属于后续回踩 | 父底回测中的早期 HL 候选，局部尚未转强 | 上涨过程中的正常 HL 候选，后来仍可能失败 |

“没有找到同类已确认小时链”不等于价格没有回踩、没有内部十五分钟波段，
更不等于已经确认上涨。它只是以同一把尺、相同可知性边界得到的不同背景。

## #13：原父段已经发生可确认的失败，不能只看旧 D 没破

在买入前一天，就能看到完整的一组父级失败证据：

| 事件 | 出现时间 | 价格 | 何时可知 |
|---|---|---:|---|
| 选用大峰 H | 10/13 04:15 | 84,073.29 | 原十五分钟确认 04:45；小时峰确认 06:00 |
| 后续小时回踩低点 L | 10/13 08:16 | 83,028.54 | 10:00 |
| 后续小时较低高点 LH | 10/13 10:12 | 83,755.57 | 12:00 |
| 跌破 L | 10/13 13:50 分钟 | 跌破 83,028.54 | 完整分钟档案不早于 13:51 |
| 13:00–14:00 收盘 | 10/13 14:00 | 83,005.05 | 14:00 |

这组 H-L-LH-破 L 的所有依据在 10/14 21:32 之前早已可知，并非用其后的亏损
倒推。旧 D 80,942.81 此时可以仍是大支撑，但原延续尝试已经失败。
后来 10/14 15:05 的小时低 81,439.47（17:00 确认）又于 18:23 被破；
18:43 低 81,326.13（20:00 确认）又于 20:52 被破。旧 D 被保留下来，
没有自动恢复这几次被破坏的较近结构。

近端触发还有另一处清楚差别：

1. 20:52 的低点 81,301.36 在 21:15 确认。
2. 21:00–21:15 的高点为 81,820.85，因此 21:15 起原突破参考是 **81,820.86**。
3. 21:15–21:30 最高只有 81,706.092，未突破；前述 81,820.85 反弹峰在 21:30 确认。
4. 到 21:30，程序改用较低的前根最高价，参考降为 **81,706.102**，21:32 才触发。

这不是同一条突破线被收复。21:15–21:30 的新回踩形状，此时其右侧
21:30–21:45 尚未完成，也不能提前认定新 HL 已按三根法确认。
需要承认 21:09 的 81,820.85 高于 20:13 的 81,724.85，局部已经出现 HH；
但局部 HH 不等于父级失败链已修复，买入价还低于这个局部 HH。

## 03:17：可保留为早期试探候选，不能提高成“已确认父级转强”

父 D 73,530.09 已于 11/08 18:00 确认，H 75,615.44 的十五分钟峰于
18:45 确认。18:16 以后有多轮十五分钟回撤/反弹，但截至 03:17，没有新的
完整确认小时低点再走出与 #13 相同的失效链。

02:58 的 L 73,629.55 在 03:15 确认；它相对父 D 是高低点候选，但相对
02:29 的 73,711.65 仍是局部 LL。03:00–03:15 的完整 K 线守住该低点，
03:17 在第一根新 K 线内突破前根高 + $0.01，参考 **73,867.005**。
没有 #13 那样先形成一段确认反弹、原线没突破、再降低参考价的过程。

当时仍低于 02:40 已确认的局部峰 74,117.77，局部降高降低未完成修复。
故正确标签是**主底回测的早期 HL 候选 / 反转试探**，不是确定的上涨延续。
同分钟 B1 优先，原 C 候选仍为 held，没有额外 C 成交。

该回撤占所选 D-H 推进约 95.23%；#13 约 88.55%，#90 约 56.42%。
这些比例仅描述深度，不作为过滤阈值。年龄、深度本身都不足以证明归属。

## #90：应保留为正常回踩候选，不能因它后来亏损而否定

父 D 80,283.50 于 14:00 确认。入场前的十五分钟推进证据是：

| 结构 | 出现时间 | 价格 | 确认时间 |
|---|---|---:|---|
| 前峰 | 14:00 | 81,214.96 | 14:30 |
| 回踩低 | 14:16 | 80,610.34 | 14:45 |
| 提高的峰 | 14:37 | 81,240.96 | 15:00 |
| 再提高的峰 H | 16:02 | 81,720.51 | 16:30 |
| 新回踩 L | 16:46 | 80,909.68 | 17:15 |

L 高于此前 80,610.34；新反弹峰之前没有与 #13 相同的确认小时底失败链。
17:15 后第一根新 K 线在 17:16 越过前根高，参考 81,358.58；没有降低首次
触发参考，也没有 L 后已经确认却未收复的另一反弹峰。

按这里的归属定义，它应保留为正常 HL 候选，即使它后来亏损。
但它在入场时**尚没有所选 16:02 峰的完整小时级确认**。如果为了“同一级别”
而强制所有峰/低点都等小时三根确认，或强制近端 HL 通过 P1 两根守底，
都会把这个原时点挡住。这不是本定义要求，也没有被接入执行。

## 局限、复现与保护

本次可明确区分的是原父段失败、近端反弹次数、参考线下移，以及候选/完成
验证的差别。三例不足以证明某个自动父子波段分级方法通用于整月，尤其不能
由“小时转折缺席”自动判为通过。后续需要盲标盈利、亏损、outside bar 及
新父段重建案例，但本次不新增参数或进行这些重放。

`scripts/audit_btc_parent_wave_identity.py` 从已保存真实观察中，先剔除原入场
分钟及后续所有分钟，再计算完整十五分钟/小时转折；原买价单独引用。
包含后续结果的原资料与严格前缀得到完全相同结构快照，输出中不含后续盈亏。
证据在 `reports/btc_parent_wave_identity_2026_11_09/ENTRY_TIME_EVIDENCE.json`。
`PRESERVATION.json` 验证 164 个受保护文件及十三个冻结规则哈希；P1、C、
0.2、所有旧结果/调查与各指针保持不变，Live Paper 同一 worker 持续运行。
