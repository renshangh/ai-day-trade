# AI Trading Desk v3
Layered market and research desk built over the existing sector board.
Last Updated: 2026-10-06
Status: Development
Audience: Trading Desk users and developers

## Overview

Run `python3 trading_desk/server.py` from the dev checkout and open `http://127.0.0.1:8799/`. The existing sector board remains at `/board`, with its existing API-backed views and charts. The v3 page combines the CIO Brief, scorecard, AI Economy model, Onchain Finance Buildout, ten report sections, Research Lab, Thesis Tracker, Opportunity Pipeline, and Decision Log.

A dated report snapshot drives the CIO Brief. The AI Economy Score is an equal-weight average of six analyst-entered 0–100 component assessments and appears only when every component has a source URL. The other scores are manual assessments that require a source or method note. Top 5 Changes are sourced developments entered for a report after a baseline report. No current market values are seeded or inferred.

The Altcoin Health Monitor combines eight sourced analyst assessments using the displayed weights. It has no score until all eight are present. The AI Coin Dashboard loads real daily bars from the existing `/api/crypto` route one asset at a time and labels each feed and last bar date. It calculates 1-bar and 7-bar close changes only from returned bars. Missing data stays unavailable. TVL, ETF flows, relative strength, news, and institutional activity require separate sourced observations; they are not inferred from price.

Thesis reviews record dated confidence, trend, supporting evidence, contradicting evidence, and a source link. Opportunity stages and decision outcomes can be updated. The Agent Economy, AI × Blockchain, RWA, Early Signals, and Research Lab panels accept dated sourced observations. Reports, reviews, opportunities, decisions, and observations are saved by the local server to ignored, private `trading_desk/v3_state.json`; a browser recovery copy and JSON export are also available. Writes use a revision check so an older tab cannot silently overwrite newer work. The old preview browser key is read for migration into v3 when the server has no data. Watchlists and research themes are structural examples, not current recommendations.

Onchain Finance Buildout is a five-layer daily review on both `/` and `/board?view=ai-crypto`: Digital Money, Onchain Markets, TradFi Bridge, Infrastructure Rails, and Agentic Finance. COIN and CRCL are the anchor securities. Watchlists are research scope, not assertions of current adoption or investment recommendations. The date selector defaults to the New York calendar date; prior dates remain reviewable.

Use “Record a sourced daily entry” on the main desk to capture a development, evidence type (announcement, pilot, live usage, or regulatory development), source URL, portfolio implications and an optional observed metric with unit/scope. Entries append to the existing revisioned `observations` collection under the `Onchain Finance Buildout` theme, so browser recovery, private local storage and JSON export include them. The board reads that same file and links back to the main desk for entry. Save status remains in the desk's existing sync indicator; a browser entry is not proof of server persistence.

Day-over-day deltas require exactly one matching sourced observation on the previous calendar date, with the same layer, metric name and unit/scope. Enter values from consistent methodology; the desk cannot verify source claims. Missing values, dates or ambiguous baselines produce unavailable comparisons, and a zero baseline has no percentage delta. No metrics or daily news are auto-populated, and an unreviewed layer does not imply no change. Add separate entries for separate metrics.

The original eight-layer infrastructure map remains in an expandable reference section. Public stock links and associated token links retain ticker labels; tokens do not represent company equity. The existing `#coins` anchor, `ai-crypto` view key, filenames and `CryptoFinanceInfra` API remain compatible. Additional crypto research and all earlier observations remain available.

Proposed North Star: the share of daily thesis decisions supported by dated adoption evidence and an explicit COIN / CRCL implication. Proposed weekly OKRs: review all five layers on each review day; link every recorded development to a source; distinguish actual usage from announcements; record both supporting and contradicting evidence. These are targets, not measured performance.


## Symbol charts and Canton

Every listed stock/token in the five-layer watchlists and original map has a
chart link. On the sector board, selecting it loads the existing chart below;
on the main desk it opens the board with that symbol selected. The separate
arrow retains the external market link. Unlisted companies stay unlinked.

Canton uses the desk label `CCCAUSD`, mapped to Kraken `CCUSD` (CC/USD), not the
unrelated Chemours stock `CC`. Verified Kraken USD pairs use completed daily
UTC OHLC and base-token volumes. The last forming interval is excluded; gaps
stay gaps, and malformed/duplicate candles are rejected. Missing feeds clear
previous candles and show unavailable. Tokens without a configured daily feed
still have their external market link. Public-provider requests receive no
Alpaca credentials. No orders, secrets or environment variables are added.

Pair and candle contract: `onchain_crypto.py`. Regression coverage:
`tests/test_onchain_crypto.py` and `tests/test_crypto_infra.cjs` under
`trading_desk/`. The North Star remains sourced, explicit thesis decisions;
charts supply dated market context without substituting for adoption evidence.
